Como funciona

Entenda o fluxo on-chain do mural e dos envios.

1. O que é o EscrowFactory?

É um contrato inteligente já publicado na Polygon em 0x5C305aCFF5cDFAee90276c2acEA4Aa841f7062d8. Cada ordem de venda gera um escrow próprio que guarda os tokens do vendedor.

2. O fluxo de uma ordem

1. Vendedor aprova o token → 2. Cria ordem (token travado) → 3. Comprador aprova o token pedido → 4. Executa a ordem → 5. Troca atômica
  1. Aprovar: o vendedor autoriza a fábrica a mover o token oferecido (approve).
  2. Criar ordem: criarOrdem(tokenOferecido, tokenDesejado, valorOferecido, valorDesejado); a fábrica cria o escrow e puxa os tokens do vendedor.
  3. Aprovar (comprador): o comprador autoriza o escrow a mover o token pedido.
  4. Executar: executarTroca() no escrow — troca atômica na mesma transação.
  5. Cancelar: enquanto ninguém executou, o vendedor recebe os tokens de volta.

3. Proteções do app

  • Só ordens com tokens da lista abaixo podem ser executadas; ordens com token desconhecido ficam bloqueadas.
  • Cada ordem mostra se é executável (ativa e com o token travado no escrow).
  • Antes de assinar, o app relê os dados pela sua carteira, confere saldos e simula a transação.
  • Transações são bloqueadas fora da Polygon (chainId 137).

4. Tokens suportados

Cada token é conferido on-chain (decimais e símbolo) ao abrir a página; se não conferir, é desativado.
