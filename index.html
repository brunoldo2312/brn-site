Como funciona (explicação)

Entenda o fluxo on-chain do mural BRN ⇄ USDC.

1. O que é o EscrowFactory?

É um contrato inteligente já publicado na Polygon no endereço 0x5C305aCFF5cDFAee90276c2acEA4Aa841f7062d8. Ele funciona como uma fábrica de escrows: cada vez que alguém cria uma ordem de venda, a fábrica implanta um novo contrato de escrow só para aquela ordem.

2. O fluxo de uma ordem

1. Vendedor aprova BRN → 2. Cria ordem (BRN travado) → 3. Comprador aprova USDC → 4. Executa a ordem → 5. Troca atômica
  1. Aprovar BRN: o vendedor autoriza a fábrica a mover seus BRN (approve).
  2. Criar ordem: chama criarOrdem(...). A fábrica cria o escrow e puxa os BRN.
  3. Aprovar USDC: o comprador autoriza o escrow a mover seus USDC.
  4. Executar: o comprador chama executar(). O contrato faz a troca atômica.
  5. Cancelar: enquanto ninguém executou, o vendedor pode chamar cancelar().

3. Por que é seguro?

A troca acontece dentro do contrato, na mesma transação. Ou as duas pernas (BRN e USDC) acontecem juntas, ou nada acontece — é atômico.

4. O que este front-end faz

  • Lê o mural direto da blockchain via proxy /rpc (sem CORS).
  • Mostra o contador de ordens ativas e o estado de cada uma.
  • Faz o approve automático de BRN (fábrica) e de USDC (escrow).
  • Permite criar, executar e cancelar ordens pela MetaMask.
